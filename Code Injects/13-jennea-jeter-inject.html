JavaScript Architecture

Four JS files power the patch's control and sync logic. Max loads them at runtime — if missing, scripted features fail.

active_stems_status.js
Tracks which stems are active and builds the UI status text in real time.
song_sync_clock.js
Maintains shared timing state so all events stay aligned to song playback.
stem_availability_gate.js
Enforces valid stem controls per song — prevents invalid trigger combinations.
simple_stem_router.js
Routes keyboard controls into the correct play/stop paths for each stem.
