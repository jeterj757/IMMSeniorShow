Project Context

Sampling History as an Interface

Visitors use a keyboard-and-mouse interface to trigger isolated stems from related songs. Each stem acts like a node in a sonic family tree, making relationships between source material and later music audible.

The project moved from a Makey Makey felt-pad prototype into a more reliable software-controlled final build. The live mixing feature was removed so playback, timing, and stem availability could stay stable.

Final software-first demo using the updated keyboard-and-mouse control system.
