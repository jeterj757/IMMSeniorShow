Role

Web Designer & Brand System Lead

I built the full digital and print identity for the 2026 IMM Senior Show: the public website, student directory, posters, flyers, event graphics, and custom HTML/CSS/JS injects.

The direction moved from Canva wireframes into a woodsy, nature-meets-brutalism system that could support six tracks and 41 students without feeling disconnected.

Code Inject Workflow

Building Around Squarespace

The site uses code injects: custom HTML, CSS, and JavaScript blocks added on top of Squarespace pages to create interactions the template could not handle by itself. That included the homepage, project directory, student pages, hunt flow, maps, modals, filters, and brand kit previews.

AI tools were useful in my workflow when I treated them like an iteration partner instead of a replacement: I used them to test layout directions, generate throwaway versions, debug CSS/JS issues, and compare approaches before rebuilding the final pieces with my own design decisions.
